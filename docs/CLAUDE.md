# Claude Code 本机实时接入

「Claude」来源把本机正在运行的 Claude Code 会话映射到同一份场景快照。它与「Codex」「模拟」并列，同一时间只运行一个实时来源；上次选择的实时来源会在重启后恢复。

本文说明实现方式与使用边界，不代表真实锁屏、睡眠唤醒和多显示器验收已经通过。

## 读取链路

1. 每秒读取一次 Claude Code 的会话登记目录 `~/.claude/sessions/<pid>.json`（设置了 `CLAUDE_CONFIG_DIR` 时使用该目录）。登记文件提供会话ID、名称、启动目录和运行状态。
2. 用进程号确认登记的进程仍在运行，并排除启动时间晚于登记时间的进程号复用；进程已退出的登记文件不再计入。
3. 只对工作中、等待确认或已观察过的会话，读取 `projects/<目录>/<会话ID>.jsonl` 的末尾，补充阶段、工具名、最近一条可见助手进展和本轮开始时间。
4. 结果交给与 Codex 相同的投影逻辑，写入共享快照；屏保只读该快照。

## 画面中的状态

| 登记状态 | 画面含义 |
| --- | --- |
| `busy` | 工作中。 |
| `waiting`，且本次运行中观察到它工作过 | 等待确认，例如权限提示或打开的对话框；确认仍在 Claude Code 中操作。 |
| `waiting`，但从未观察到它工作 | 视为待机。长期停在对话框的旧终端不占用屏幕。 |
| `idle` 且已观察到本轮结束 | 本轮完成，计入完成统计。 |
| `idle` 及其他未知状态 | 待机，不证明任务成功。 |
| 找不到会话登记目录 | 显示未连接。 |

启动时已经待机的会话不占用屏幕；只有观察到活动的会话结束后才保留状态屏。登记文件没有错误状态，因此本来源不会显示「出错」。

## 数据与边界

- 只读：不写入 Claude Code 目录，不修改设置或 hooks，不读取凭据，不启动任务，也不回答权限请求。
- 只提取公开助手文本、工具名和时间。工具参数、工具输出和思考正文不进入共享状态；思考块仅用于标记「思考中」。子代理行不计入主会话。
- 首次读取限制在文件末尾 2 MiB，之后按偏移增量读取；开始事件在读取范围之外时，本轮时长留空。
- 仅覆盖本机由用户发起的会话，包括终端 CLI 和桌面应用。通过 SDK 启动的会话（入口以 `sdk` 开头，例如插件的后台会话）不显示。远端机器和云端会话不在范围内。
- 会话登记文件与日志格式不是 Claude Code 对外承诺的稳定接口，版本更新后可能需要适配。本适配基于 Claude Code 2.1.322 的本机格式。

## 验证

```sh
./scripts/test-claude-live.sh
./scripts/diagnose-claude-live.sh --expect-session SESSION_ID --expect-tool
```

测试只使用临时目录中的夹具。诊断使用生产扫描与投影逻辑，报告仅含状态、阶段和工具名，不输出标题或助手正文。
